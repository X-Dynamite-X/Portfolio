# Abd Al-Rahman Ahmad — Portfolio

A fast, animated, single-page portfolio built with pure HTML/CSS/JS (zero build step, zero runtime dependencies) featuring an Obsidian Emerald & Warm Amber theme, dark/light system-aware mode, and an interactive feature explorer for **Laravel Dev v2.5.0**.

## ✏️ Edit Content
All personal info, projects, work experience, education, and skills live in **[js/data.js](js/data.js)**.

## 👀 Preview Locally
```bash
python3 -m http.server 8765
# open http://localhost:8765
```

## 🚀 Publish on GitHub Pages
1. Create a **public** repository named **`X-Dynamite-X.github.io`**
2. Push these files:
   ```bash
   git init && git add . && git commit -m "Portfolio with CV data & Laravel Dev showcase"
   git branch -M main
   git remote add origin https://github.com/X-Dynamite-X/X-Dynamite-X.github.io.git
   git push -u origin main
   ```
3. Under **Settings → Pages**, deploy from branch **`main` / `(root)`**
4. Live at **https://x-dynamite-x.github.io**
